## Behavior Guidelines

1. **Persian & RTL Web Standards**:
   - Ensure RTL (`dir="rtl"`) layout integrity.
   - Maintain Persian typography hierarchy (Vazirmatn or system Persian fonts).
   - Touch targets must adhere to >= 44×44px.
   - Ensure high contrast ratios (WCAG 2.2 AA >= 4.5:1 for body, >= 3:1 for large text/interactive elements).

2. **UI Development & Modification Flow**:
   - Apply `antislop` as an uncompromising filter against generic AI templates.
   - Use `hallmark` and `design-taste-frontend` for layout rhythm, theme adherence, and structural variety.
   - Use `impeccable` for craft floor, micro-interactions, and visual precision.
   - Use `ux-ui-agent-skills` and `ui-ux-pro-max` for design tokens and accessible component states.

3. **Architecture & Navigation**:
   - Use `graphify` when tracing dependency or data flows between `index.html`, `style.css`, `app.js`, `config.js`, and external API endpoints.
